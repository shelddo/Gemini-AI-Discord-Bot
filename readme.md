# Gemini AI Discord Bot
This Discord Bot was made in 2024 as a hobby, using Google's Gemini AI to chat with people and use admin commands aswell. It's as unhinged as possible, so it can talk to people in a natural way.

The Bot is told to respond in portuguese, but it can also talk other languages, since it's Gemini AI. You just need to write the `BOT_INSTRUCTIONS` and other input texts in english.

## How to use

First of all, create an .env file with the following lines:

```
GOOGLE_API_KEY = "your_api_key"
BOT_TOKEN = "your_discord_bot_token"
```

### 1. Run the following commands on your terminal

1. `pip install google.genai`
2. `pip install dotenv`
3. `pip install discord`
